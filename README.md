# WJKLL小站

纯静态玻璃拟态官网（HTML / CSS / 原生 JS，零构建、零后端，AI），任意静态托管即可运行。
这个仓库记录了我们逐步打磨出来的成果——从最初的玻璃拟态页面，到导航、动效、课程表、性能优化等一整套功能。

- 最新更新：v0.0.8e（质量更新）

---

## 我们做的工作

### 导航与菜单
- **双胶囊导航**：左品牌 + 右功能两个毛玻璃胶囊；鼠标靠近顶部自动出现，离开后按滚动方向隐藏。
- **变形生长菜单**：点击 ☰ 从按钮右上角弹性生长（`scale(0.3)→1` + `cubic-bezier(0.34,1.56,0.64,1)`），毛玻璃 28px，菜单项逐项错峰淡入；内含立即咨询、首页、关于我们、滚木服务、宿舍成员，以及**设置/清除本地背景**。
- **深浅色切换与菜单按钮并排**：主题按钮紧贴 ☰ 左侧，按压回弹一致，胶囊背景联动。
- **胶囊弹簧拖拽**：长按整个胶囊可拖拽（对数弹簧阻尼、越拖越费劲、无硬墙），松手弹性归位；修复了拖拽时导航缩回、拖出链接、鼠标拖完不归位等问题。

### 毛玻璃与光效
- 移除"液态玻璃"折射扭曲，回归干净的普通磨砂。
- **伴随式光效**：所有玻璃组件跟随鼠标的光斑；修复跨卡"被拉扯"，保留轻微拖尾；光效扫描支持补扫，动态创建的组件（迷你课表每一行等）也有光效。

### 卡片与动效
- 卡片 / 统计块 / 里程碑悬停**轻轻跃起**，背景与阴影同一条弹性曲线柔和过渡（用相对定位位移，不影响布局、不破坏磨砂）。
- 交互元素禁止按住拖选文字。

### 主题与壁纸
- **跟随系统深浅色**：`prefers-color-scheme` 跨平台自动识别、实时响应；手动切换后保存覆盖；首屏无闪色。
- **双壁纸**：浅色用默认壁纸、深色用太空星空壁纸（已压缩），切换时**淡入淡出**；支持上传本地壁纸（IndexedDB，纯本地）。

### 滚动条
- 覆盖式自定义滚动条：悬浮于背景之上、不占布局不偏移背景；滚动渐显、静止渐隐、鼠标靠近自动出现；支持点击跳转与拖拽跟手；黑灰磨砂外观。

### 课程表
- 完整可编辑课程表（`schedule.html`）+ 首页迷你课表（自动滚到今天、上下端渐变淡出）。
- **Excel 导入**（`.xls/.xlsx`）：支持"网格课表"（节次+星期~日、`★` 分隔、周次区间如 `1-16`/`9-16`）与列字段两种格式，自动定位表头行，最多 16 节次。
- **课程卡片颜色自定义**；单双周 / 周次区间显示。

### 移动端性能专项
- 经性能 trace 分析调优的**省性能毛玻璃**：主要面板 6px 小半径、去 `saturate/brightness`、小徽标实底、隐藏背景光斑，兼顾流畅与省电。
- 移动端胶囊收窄居中、迷你课表多行卡片布局、浅色课表对比度增强。

## 技术栈

- 纯 HTML / CSS / 原生 JavaScript（无框架、无构建、无后端）
- 字体：Outfit（Google Fonts）
- 第三方依赖：SheetJS（xlsx，CDN，仅课程表导入页按需加载）
- 数据存储：`localStorage`（主题、课表）+ `IndexedDB`（上传壁纸）——全部**本地保存，不上传服务器**

## 运行与部署

- 纯静态项目：GitHub Pages / Vercel / Nginx 等任意静态托管均可；本地直接双击 `index.html` 即可预览。
- 修改 CSS/JS 后注意浏览器缓存（资源带 `?v=` 版本号）。

## 数据与隐私

所有用户数据（主题、课程表、壁纸）仅保存在访客浏览器本地，不上传任何服务器；仅课程表导入页会从 CDN 加载 SheetJS 库代码。
